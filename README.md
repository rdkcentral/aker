# aker

Aker is an experimental MAC address blocking scheduler.

For details:

https://github.com/Comcast/aker/wiki

## Origin

This repository is based on the original
[aker](https://github.com/xmidt-org/aker) source code
maintained under the xmidt-org organization. The code was copied into the
rdkcentral organization, where ongoing maintenance and development now take place.

- Original project: https://github.com/xmidt-org/aker
- Current repository: https://github.com/rdkcentral/aker

# Building and Testing Instructions

```
mkdir build
cd build
cmake ..
make
make test
```
